# 温习有序 · 第二版

个人学习计划：按作息排程、根据反馈推荐科目、限量补做、专注计时、主动回忆和学习统计。

## 使用

GitHub Pages 从 main 分支的根目录发布。index.html 包含页面所需的全部样式与程序，favicon.svg 为站点图标。

普通日默认安排在 16:30、17:25 和晚饭后，避开 18:30–19:30；补习日单独处理。可切换正常、疲惫或半小时模式，未教及明确不考的课题不会自动选入。

## 保存与同步

Pages 版记录保存在当前浏览器，请定期导出 JSON 备份。暂停或刷新可恢复计时，本机最多保存三个恢复点。

需要账号同步时，请使用设置中的[原网站入口](https://jun-study-compass.andyang888.chatgpt.site)。两个网站的数据独立，可导出、导入 JSON 转移。不要把个人学习记录或密钥提交到公开仓库。
